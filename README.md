# QZoneLocalLike Tech Notes

> 一款 Android 本地轻量化任务工具的设计复盘——以 QQ 空间点赞流程为例。

这个仓库只记录项目成果、设计思路、踩坑过程与安全边界，供个人学习和技术交流使用。

当前项目已经完成一版可运行原型，并在 Android 设备上进行了扫码登录、动态读取、基线保护、自动处理、安全暂停和失效邮件提醒测试。

## 先说明

- 本项目为非官方个人技术研究，与腾讯、QQ 或 QQ 空间不存在隶属、合作或授权关系。
- 仓库不提供完整源码、APK、账号托管、批量操作或商业代挂服务。
- 不公开登录凭据、接口地址、完整请求参数、签名过程及可直接部署的调用链路。
- 不研究或提供验证码绕过、访问限制规避、风控对抗等内容。
- 平台出现验证、限制或异常时，设计目标是主动暂停，避免继续请求。

QQ、QQ 空间等名称仅用于说明项目的兼容对象和测试环境。

## 为什么做这个项目

曾经使用的第三方服务常会集体失效，使用者既不知道问题发生在哪里，也无法自行排查。

这个项目希望验证另一条路线：把任务放回自己的 Android 设备，在本机完成状态保存、低频检查、目标筛选、去重和异常暂停。它更像一个轻量化的本地任务实验，而不是面向多人提供服务的平台。

## 这套设计最重要的部分

功能本身并不复杂，真正花时间的是决定什么时候应该停止：

- 首次运行只建立基线，不处理历史内容。
- 已处理目标写入本地记录，避免重复动作。
- 网络结果不明确时不盲目重发。
- 登录失效、出现验证或访问限制时暂停。
- 连续失败超过安全阈值时暂停并给出提醒。
- 日志只保留排查所需信息，并隐藏敏感字段。
